# Healysis — Hackathon Requirements & Compliance

## Selected Track
**03 — Smart Health & Supply Chain Resilience**

The challenge calls for a federated AI platform with visibility into medicine stocks, bed availability and medical personnel attendance; demand forecasting; early stock-out warnings; cross-district redistribution; and shared predictive modelling across Indian states.

## Non-negotiable requirements
- [ ] Working prototype, not just a concept
- [ ] End-to-end core use case
- [ ] Meaningful Google AI integration
- [ ] Real or realistic data
- [ ] Designed for India-scale expansion
- [ ] Multilingual/voice support evaluated where relevant
- [ ] Public or access-granted GitHub repository
- [ ] 3–5 minute demo video
- [ ] 10–12 slide pitch deck
- [ ] 2–3 line solution description
- [ ] Live deployed link
- [ ] Original/licensed code with attribution

## Google stack strategy

**Mandatory:** meaningful Google AI integration.

### P0
- Gemini API / Google AI Studio
- Cloud Run deployment
- Predictive forecasting
- Realistic/public data

### P1
- Vertex AI
- BigQuery
- Firebase Auth
- Google Maps Platform
- Cloud Translation API

### P2
- Speech-to-Text / Text-to-Speech
- Gemini multimodal

**Important:** the event brief makes Google AI integration mandatory. The individual tools listed on the event page are recommended/supported, not all individually mandatory.
